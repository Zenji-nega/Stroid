# Stroid

بيئة تطوير أصلية متكاملة (IDE) كتطبيق Android: محرر أكواد احترافي، Terminal حقيقي، مدير toolchains، Git/GitHub، معاينة مواقع، بناء تطبيقات، ووكيل ذكاء اصطناعي يتحكم بأدوات التطبيق.

> الحالة: مرحلة التخطيط. هذا الملف هو الخطة المعتمدة للمشروع.

---

## 1. الأهداف

- محرر أكواد مصمم للهواتف والتابلتات: سلس وخفيف بدون تأخير أو تعليق.
- تثبيت لغات البرمجة مع أدواتها (Toolchain) بضغطة زر.
- Terminal حقيقي (PTY) بتجربة مشابهة لـ Termux.
- إدارة ملفات ومشاريع، ودعم Git/GitHub.
- تطوير تطبيقات وتصديرها، وتطوير مواقع وعرضها.
- وكيل ذكاء اصطناعي بمفتاح API يتحكم بجميع أدوات التطبيق.
- كل وظيفة تُبنى بأنسب لغة لها: أداء أعلى واستهلاك موارد أقل.

## 2. القرارات المعمارية

### 2.1 التوزيع: خارج Google Play
- التوزيع عبر GitHub Releases و F-Droid.
- التطبيق يستهدف **targetSdk 28** حتى نتمكن من تشغيل ملفات تنفيذية من مجلد التطبيق (قيد W^X في Android 10+ يمنع ذلك عند targetSdk >= 29). هذا نفس النهج الذي يستخدمه Termux.
- يُنظر لاحقاً في وضع بديل (proot) لو احتجنا نسخة متوافقة مع Play Store.

### 2.2 اللغات (لغتان فقط لتقليل تعقيد الربط)
| الجزء | اللغة | السبب |
|---|---|---|
| نواة المحرر (rope، تلوين tree-sitter، بحث، فهرسة) | Rust | أداء عالٍ، استهلاك ذاكرة منخفض |
| PTY و Terminal emulator | Rust | تحكم دقيق بالعمليات والإدخال/الإخراج |
| Git | Rust (gitoxide) أو libgit2 | سرعة وبدون الاعتماد على git خارجي |
| الواجهة | Kotlin + Jetpack Compose | أصلية، مناسبة للهواتف والتابلتات |
| رسم نص المحرر | Kotlin (Canvas/View مخصص) | Compose Text ثقيل للملفات الكبيرة |
| إدارة الملفات والمشاريع | Kotlin | تكامل مع Android |
| معاينة المواقع | Kotlin + WebView + خادم محلي (Rust) | |
| مدير الـ toolchains | Kotlin + سكربتات shell | |
| وكيل الذكاء الاصطناعي | Kotlin | شبكة وواجهة، بدون حاجة لأداء حرج |

الربط بين Kotlin و Rust عبر JNI (مثلاً uniffi أو jni-rs).

### 2.3 هيكل المشروع (مقترح)
```
stroid/
├── app/                 # تطبيق Android (Kotlin, Compose)
├── core/                # Rust workspace
│   ├── editor/          # rope, undo/redo, تحديد، multi-cursor
│   ├── syntax/          # tree-sitter
│   ├── terminal/        # PTY + VT100/xterm emulator
│   ├── git/             # عمليات Git
│   ├── search/          # بحث وفهرسة
│   └── server/          # خادم معاينة محلي
├── toolchains/          # وصفات تثبيت اللغات (manifests + سكربتات)
├── docs/
└── README.md
```

## 3. المراحل

### المرحلة 0: الأساس
- إنشاء مشروع Android (targetSdk 28، minSdk 26) و Rust workspace وربط JNI.
- CI عبر GitHub Actions: بناء APK لمعمارية arm64-v8a.
- بيئة bootstrap: حزمة مجلد `$PREFIX` أساسية (shell، coreutils، apt/pkg) على نمط Termux.
- **معيار الإنجاز:** تطبيق يفتح ويشغّل دالة Rust عبر JNI، ويبني تلقائياً.

### المرحلة 1: المحرر + الملفات + Terminal (نموذج أولي)
- محرر: rope، undo/redo، تحديد، multi-cursor، تلوين tree-sitter، أرقام الأسطر، بحث/استبدال، طي الكود.
- واجهة متجاوبة: تبويبات، تقسيم الشاشة على التابلت، لوحة مفاتيح إضافية (Tab, Ctrl, Esc, أقواس).
- مدير ملفات ومشاريع: شجرة ملفات، إنشاء/حذف/نقل، فتح مجلدات، SAF للتخزين الخارجي.
- Terminal حقيقي: PTY، ألوان، جلسات متعددة، لصق/نسخ، اختصارات.
- **معيار الإنجاز:** فتح ملف 10MB بدون تعليق، وتشغيل `ls`/`vim`/`python` في الـ terminal.

### المرحلة 2: Git/GitHub + معاينة المواقع
- Git: clone, status, diff, stage, commit, branch, merge, pull/push.
- تسجيل الدخول لـ GitHub (OAuth device flow / token)، إدارة SSH keys.
- واجهة diff وحل التعارضات.
- معاينة مواقع: خادم محلي + WebView، إعادة تحميل تلقائية، أدوات المطور (console).
- **معيار الإنجاز:** clone مشروع، تعديل، commit، push، ومعاينة موقع HTML/JS.

### المرحلة 3: مدير الـ toolchains
- مدير حزم بوصفات (manifests): Python, Node.js, Rust, Go, C/C++ (clang), Java/Kotlin, PHP, Ruby, Lua.
- تثبيت بضغطة زر، تحديث، إزالة، تعدد الإصدارات، تهيئة PATH تلقائياً.
- LSP: تشغيل language servers وربطها بالمحرر (إكمال، أخطاء، انتقال للتعريف).
- تشغيل/Debug بأوامر جاهزة لكل لغة.
- **ملاحظة:** الدعم لقائمة لغات مختبرة على ARM/bionic وليس لأي لغة.
- **معيار الإنجاز:** تثبيت كل لغة بالقائمة وتشغيل "Hello World" بنجاح.

### المرحلة 4: وكيل الذكاء الاصطناعي
- إعداد مزوّد الـ API (Anthropic وغيره) ومفتاح API مخزّن في Android Keystore.
- أدوات للوكيل: قراءة/كتابة/تعديل الملفات، تشغيل أوامر terminal، Git، تثبيت toolchains، بحث بالمشروع، فتح معاينة.
- نظام صلاحيات: العمليات الخطيرة (حذف، push، تشغيل أوامر، تثبيت) تتطلب موافقة المستخدم، مع وضع تلقائي اختياري.
- سجل أحداث للوكيل وإمكانية التراجع عن تعديلاته.
- دعم MCP لإضافة أدوات خارجية.
- **معيار الإنجاز:** الوكيل ينشئ مشروعاً، يكتب كوداً، يشغّله، ويصلح أخطاءه بطلب واحد.

### المرحلة 5: بناء وتصدير التطبيقات
- بناء Android: aapt2, d8, apksigner، ثم دعم Gradle.
- توقيع APK، إدارة keystores، تصدير APK/AAB.
- قوالب مشاريع: Android (Kotlin)، ويب، Python، Node.
- معالجة قيود الرام وإعدادات تخفيف الاستهلاك.
- **معيار الإنجاز:** بناء مشروع Android كامل وتثبيته من داخل التطبيق.

### المرحلة 6: التحسين والإصدار
- تحسين الأداء والبطارية والذاكرة، وقياسها (benchmarks).
- حل مشكلة Phantom Process Killer (Android 12+) عبر foreground service وإرشاد المستخدم.
- إضافات/Plugins، ثيمات، دعم لوحة مفاتيح فيزيائية.
- الإصدار التجريبي ثم المستقر على GitHub Releases و F-Droid.

## 4. المخاطر والحلول

| الخطر | الحل |
|---|---|
| قيد W^X في Android 10+ | targetSdk 28 + توزيع خارج Play Store |
| Phantom Process Killer (Android 12+) | Foreground service + دليل للمستخدم لتعطيله |
| عدم توافق أدوات مع bionic/ARM | قائمة لغات مختبرة + patches + خيار proot/glibc |
| ثقل بناء Android على الجوال | البدء بـ aapt2/d8 ثم Gradle مع إعدادات رام مخففة |
| أداء رسم نص المحرر | عرض مخصص (Canvas) + نواة Rust + عرض الأسطر المرئية فقط |
| تعقيد اللغات المتعددة | الاكتفاء بـ Kotlin + Rust |
| أمان الوكيل | صلاحيات + موافقات + سجل + Keystore للمفاتيح |

## 5. معايير الجودة
- فتح التطبيق أقل من ثانية ونصف على جهاز متوسط.
- تمرير وكتابة بـ 60fps على ملفات كبيرة.
- استهلاك ذاكرة منخفض في الخلفية.
- اختبارات وحدة لنواة Rust، واختبارات واجهة لـ Android.
